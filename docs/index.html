What gets soldered?

Header pins to the XIAO and Feather Friend only, unless securely attached already. Breadboard jumper wires plug in and pull out.

What happens after testing?

Move the electrical connections to solderable perfboard, using sockets so the XIAO stays removable. No need to desolder its headers.

Illustrative board placement. The chosen hole map assumes a front-side-up XIAO with USB-C pointing left. Refer to the Seeed/Adafruit pinout documentation and check continuity before power. This wiring plan has not been physically bench-tested. Seeed XIAO pinout · Adafruit Feather Friend pinout.

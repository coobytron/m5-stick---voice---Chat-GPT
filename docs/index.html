STEP 01 / 03

Solder the headers.

Two 7-pin male headers are held square by the breadboard. Solder each XIAO pad to its header pin with USB and battery disconnected. The breadboard itself is never soldered.

Connection reference

Assembly notes

Illustrative model, not a production CAD drawing. Geometry, spacing and routed wire positions are approximate. Verify the actual silkscreen and physical pin locations before applying power. Do not use this model for precise enclosure dimensions.
Read build notes

Component set

Seeed XIAO ESP32-S3 Sense + camera/microphone expansion; Adafruit eInk Feather Friend (microSD slot used for WAV); 2.13" four-color e-ink; breadboard; tactile switch; USB-C for initial testing. PowerBoost omitted.

New XIAO concept variant. The repository's original M5StickC Plus firmware is a separate design and is not directly compatible. Reference-only 3D model; firmware and physical wiring have not been validated with the assembled hardware.
